# AI Smart Study Planner

## 📌 Description

This project is a Smart Study Planner built using Next.js. It helps students manage their study subjects and generate an intelligent study plan using AI. The goal of this application is to improve productivity and help users organize their learning efficiently.

## 🚀 Features

* Add, edit, and delete subjects
* Generate AI-based study plan
* Auto-update plan on changes
* Save and manage study plans
* Dark mode support

## 🛠️ Tech Stack

* Next.js (Full Stack)
* React.js
* MongoDB
* Tailwind CSS
* OpenAI (AI feature)

## 🎯 Purpose

This application is designed to go beyond basic CRUD functionality by integrating AI to provide meaningful study recommendations and enhance user productivity.
